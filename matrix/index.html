開啟 Vision Pro 沉浸瀏覽

由於 Apple 隱私保護限制，我們無需開啟複雜的平面與網格偵測。您只需要在 AVP Safari 啟用最基礎的 XR 功能：

檢查 Safari 實驗功能旗標 (Feature Flags)

1. 進入 Vision Pro 的 「設定」 (Settings) ➜ 「Apps」 ➜ 「Safari」 ➜ 滾動到最底點擊 「進階」 (Advanced)。
2. 點選 「Feature Flags」。
3. 確認開啟以下兩項即可：

✓ WebXR Device API
✓ WebXR Hand Input

第二步：進入並體驗空間代碼

點擊下方「接入」按鈕。當進入後，您的真實房間透視 (Passthrough) 依然保留。與此同時，一個以您為中心的「視線數位掃描雷達」將展開，隨著您的轉頭，格線將掃描周圍的所有空間！
